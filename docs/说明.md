# cloud-mall 技术说明

## 技术栈（3.9.5）

| 工程 | 路径 | 说明 |
|------|------|------|
| jeecg-boot | `JeecgBoot/jeecg-boot` | 底层框架 **3.9.5**，`mvn install` 到本地 Maven；可按需求改底层后重新 install |
| cloud-mall | `sass-mall/cloud-mall` | 业务主工程，**只引用本地 install 的 jeecg 产物**，不拉网上的 jeecg-boot 源码包 |
| jeecgboot-vue3 | `JeecgBoot/jeecboot-vue3` | 前端原样使用，**不改**；对接 cloud-mall（等价原 jeecg-system-start） |

关系：`jeecg-boot` 打底 → `cloud-mall` 写业务 → 前端仍连 `http://localhost:8080/jeecg-boot`。

## 系统接口从哪来

`jeecg-module-system` 三个子模块分工：

| 模块 | 作用 | cloud-mall 怎么用 |
|------|------|-------------------|
| `jeecg-system-api` | 系统 API 接口定义 | 经 `jeecg-system-biz` **传递依赖**自动带入 |
| `jeecg-system-biz` | 登录/用户/角色/菜单/字典等 **Controller 实现** | `mall-web` **直接依赖**本地 `3.9.5` jar |
| `jeecg-system-start` | 官方启动入口 | **不依赖**；由 `mall-web`（`MallApplication`）替代 |

上层 `mall-web` 启动后：

- Spring 扫描 `org.jeecg` → 加载 jar 里全部系统 Controller（如 `LoginController`、`SysUserController`…）
- 路径仍是 `/jeecg-boot/sys/login` 等，与官方一致
- **不用在 cloud-mall 里重写系统接口**；vue3 调的还是依赖包里的实现

业务接口只写在 `mall-modules`（`com.mall.*`），与系统接口并存。

## 为什么前端不受影响

`mall-web` 端口 `8080`、上下文 `/jeecg-boot`，与 `jeecgboot-vue3/.env.development` 默认代理一致。系统接口走依赖 jar，路径不变 → 前端零改动。


## 模块结构

```
cloud-mall
├── mall-common     # 公共（依赖本地 jeecg-boot-base-core:3.9.5）
├── mall-modules    # 业务（商品/订单/会员等）
└── mall-web        # 启动（依赖本地 jeecg-system-biz:3.9.5 + mall-modules）
```

```
mall-web
  ├── jeecg-system-biz:3.9.5     ← 本地 Maven（install 产物）
  └── mall-modules
        └── mall-common
              └── jeecg-boot-base-core:3.9.5  ← 本地 Maven
```

## 日常流程

### 1. 改底层 / 首次环境

```bash
cd /Users/xiaobai/Deveploer/workspace/sass-mall/JeecgBoot/jeecg-boot
mvn clean install -DskipTests -Pdev
```

改了 `jeecg-boot` 任意模块后，必须重新 `install`，`cloud-mall` 才会用到新 jar。

### 2. 编译 / 启动业务后端

```bash
cd /Users/xiaobai/Deveploer/workspace/sass-mall/cloud-mall
mvn clean compile -Pdev
# IDEA 运行 com.mall.MallApplication
```

### 3. 启动前端（不改代码）

```bash
cd /Users/xiaobai/Deveploer/workspace/sass-mall/JeecgBoot/jeecgboot-vue3
pnpm dev   # 或 npm / yarn，按项目原方式
```

## 依赖找不到时（IDEA 红线）

根因通常是：**命令行 install 到了 `/Users/xiaobai/Tools/maven/repository`，IDEA 却在读 `~/.m2`**。

已在 `~/.m2/settings.xml` 把 `localRepository` 指到 Tools 仓库。若仍红：

1. IDEA → Settings → Build Tools → Maven → User settings file 选中 `~/.m2/settings.xml`
2. Local repository 确认是 `/Users/xiaobai/Tools/maven/repository`
3. 右键根 `pom.xml` → Maven → Reload project

写法对齐 `dw-platform`：子模块依赖 `jeecg-boot-base-core` / `jeecg-system-biz` **不写 version**，由 `jeecg-boot-parent` 管理。注意 3.9.5 的 groupId 是 `org.jeecgframework.boot3`（dw-platform 的 3.6.x 是 `org.jeecgframework.boot`）。
