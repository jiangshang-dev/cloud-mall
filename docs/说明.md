# cloud-mall（Fondia 单体）技术说明

## 定位

- 底层：`company/lingxi/JeecgBoot/jeecg-boot`（3.9.2）本地 install
- 业务：迁入 `mall-modules/*`（无 Controller）
- Controller：`mall-web`
- 公共：`mall-common`
- **单体**：不引入 OpenFeign / Nacos Config

## 模块

```
cloud-mall
├── mall-common          # 公共配置/常量（MapperScan）
├── mall-modules
│   ├── mall-media
│   ├── mall-user
│   ├── mall-cuisine
│   ├── mall-search
│   ├── mall-ai
│   ├── mall-interaction
│   ├── mall-member
│   └── mall-support
└── mall-web             # MallApplication + 全部 Controller
```

## 跨模块调用（替代 Feign）

| 原 Feign | 单体实现 |
|----------|----------|
| `IAiUserFeignClient` 等 | `MallLocalResolverConfig` 中 `Local*Resolver` |
| `CsUserFeignClient` / `CsSearchFeignClient` | `LocalCsUserClient` / `LocalCsSearchClient` |

## 配置要点

[`application.yml`](../mall-web/src/main/resources/application.yml)：

- `spring.cloud.nacos.config.import-check.enabled=false`
- AI 提示词：`classpath:config/agent-system-message.txt`（非 Nacos）

[`application-dev.yml`](../mall-web/src/main/resources/application-dev.yml)：库 `fondia`，端口 `8080`，上下文 `/jeecg-boot`。

## 迁移脚本

[`scripts/migrate_lingxi_modules.py`](../scripts/migrate_lingxi_modules.py)：从 lingxi biz 拷非 Controller / 非 Feign 代码；Controller → mall-web。

## 尚未迁入

- `jeecg-module-payment`（支付，依赖 Feign 调 member/user）——需要时可按同样规则迁入并改本地调用
- `jeecg-module-exam` / demo / airag 平台模块按需另定

```bash

cd /Users/xiaobai/Deveploer/workspace/company/lingxi/JeecgBoot/jeecg-boot
mvn clean install -DskipTests -Pdev

cd /Users/xiaobai/Deveploer/workspace/sass-mall/cloud-mall
mvn clean compile -Pdev
# IDEA 运行 com.mall.MallApplication
```
